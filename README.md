# 房车慢生活

「房车慢生活」角色卡的作者内容、旅行手册状态栏、素材与开发工具。运行卡片需要 SillyTavern、酒馆助手，以及配套的 SQLite Helper／DVS 插件。

房车卡在 SQLite Helper 主仓库的 `card/房车/` 子模块中开发，类型检查直接使用同一工作区的发布声明。安装、构建和测试见[开发说明](doc/README.md#开发环境)。真实酒馆部署、模型请求和测试数据写入按[部署验证流程](doc/真实酒馆部署验证流程.md)另行确认授权。
