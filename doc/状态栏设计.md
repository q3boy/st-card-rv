# 房车状态栏设计

本文描述「房车慢生活」角色卡的状态栏布局、显示内容和视觉方向。界面采用随剧情时段变化的浅色主题和一套深色主题，以独立悬浮形式显示。布局和字段以本文为准，旧效果图只供人物、物品排版与小框结构参考；阅读入口见[本卡文档导航](README.md)。

## 使用场景与范围

玩家平时看到一个纵向小悬浮框，按钮的无障碍名称为「打开旅行手册」，点击后展开标题为「旅行手册」的四个 Tab 大面板。独立酒馆助手角色脚本把一个 Vue 应用挂载到酒馆主页面，不在正文楼层中显示。悬浮栏始终读取当前聊天最新 AI 回复的当前 swipe 状态；回看历史正文不会让它改为历史数据。

状态栏提供「总览」「角色」「房车物资」「随身物品」四个 Tab，默认打开总览。人物以可展开摘要卡片组成列表，物品直接平铺显示全部内容，不提供列表／卡片两种模式切换。地图只增加旅行沉浸感，显示主角和房车两个图标并允许缩放。

状态栏不增加聊天业务表或经纬度字段，不提供业务数据编辑、导航、路线规划、地图标记弹窗、地点候选选择或地址精度校验。

## 数据来源与显示

使用现有[业务表结构](../世界书/DVS-DDL.sql)中的六张表。显示内容与字段名的关系如下；界面标题可以使用便于阅读的名称，不能改变字段含义。

| 区域 | 来源与内容 |
| --- | --- |
| 场景信息 | 世界信息：日期时间、国家、省份、城市、区域、天气 |
| 主角 | 主角信息：当前位置、状态、资金、粉丝数量；姓名来自当前玩家名称 |
| 房车 | 房车信息：油料、储备电力、储备水源、状态、行车状态、拓展状态、所在地点 |
| 角色 | 角色信息中的 NPC；主角不重复列入此表 |
| 房车物资 | 房车物资：物品名、数量、单位、说明、状态、存放位置 |
| 随身物品 | 随身物品：持有人、物品名、数量、单位、说明、状态 |

值恰为「未知」或缺少的文本可显示「—」，不生成额外事实；「未知原因」等有效描述、数字 0、负好感度和已知的「无」正常显示。房车物资数量按现有整数规则显示，随身物品不强制取整。资金和粉丝数量可用万、亿作紧凑显示，展示格式不写回业务数据。

## 总览

例如世界时间为 18:40、房车正在行车时，面板使用傍晚暖橙配色，场景卡显示「傍晚」，房车卡显示「行车」标签与傍晚行车图。停车后配图按最新变量换成驻车或拓展展开图。`状态`文字原样显示，不用于猜测配图。

宽屏总览分两列，左列依次为场景信息、房车，右列依次为地图、主角，宽度约 52∶48；两列各自纵向排布，房车与主角卡填满剩余高度。窗口不宽于 650px 时按场景信息、房车、地图、主角的顺序纵向排列。

场景信息采用分组排版：区域与山峦图标作为地点标题，国家／省份／城市与位置图标作为辅助文字；日期、时间和天气分别配日期、时钟、固定晴云图标。天气文字原样显示，不依天气内容切换图标。长地名与天气描述自然换行。

主角标题只显示「主角」，玩家名仍用于随身物品默认持有人。主角区域先显示当前位置和状态，随后显示资金、粉丝数量，数值与正文使用一致字号和字重。房车标题保留三轴图标，房车区域先显示油、电、水，再显示车况、拓展状态和所在地点。主角位置和房车位置始终分别显示。

房车卡先排文字，再放底部独立配图区；主角卡只排文字。房车图片等比贴底，宽度为卡片的 100%，只裁去顶部透明天空，保持完整车身。展开图的窗口略高于行车、驻车图，长文字自然撑高卡片。图片保持 Alpha 和 `opacity: 1`，不横向拉伸或对整图淡出。

资源使用数值加细进度条，容量取自[房车设定](../世界书/房车设定.txt)：柴油合计 1000 L、电池 72 kWh、清水 1000 L。例如「电力 37.15 / 72 kWh」。进度条仅用于显示，不参与结算或改变原值。

地图卡使用固定的地图显示区高度，具体尺寸随窗口断点调整，见 [App.vue](../状态栏/App.vue)。地图上只放人物和车辆两个图标，配简短图例，保留地图供应商要求的标识。两个标记重合时只在显示层稍微错开图标，方便辨认，不更改查询所得坐标。

## 角色 Tab

每位 NPC 是一张卡片。摘要显示姓名、年龄、身份、同行状态、当前位置、当前状态和好感度；昵称在已知时作为姓名旁的辅助文字。好感度保留正负号和原数值，不换算成百分比。

点击卡片摘要或展开箭头后，在原卡片下方展开详情，再次点击可收起。展开区保留摘要，并按下列分组展示完整资料。

| 分组 | 字段 |
| --- | --- |
| 外貌与穿着 | 相貌、身材、穿着 |
| 背景与处境 | 生活背景、当前处境 |
| 性格与表达 | 核心特质、行为模式、在意与反感、说话风格 |
| 相遇与关系 | 相遇情境、对主角观感 |
| 心声 | 心声，使用柔和底色的文字区块 |

姓名旁排列有效昵称、年龄与身份，长内容自然换行。宽屏摘要卡按两列排列；点击一张卡片后，该卡展开并独占一行，其余卡片仍按两列排列。展开资料用两个实际列容器组织：左列依次为外貌与穿着、背景与处境；右列依次为性格与表达、相遇与关系；NSFW 信息与心声各独占一行。NSFW 标题与上方分组使用相同字体、字号、字重、字距和强调色；字段在宽屏按左右两列排列，两列之间不加竖向分割线；窄屏每行一项。字段名与内容的字体、间距和颜色沿用上方资料。窗口不宽于650px时使用单列，阅读顺序为外貌、背景、性格、关系、NSFW 信息、心声。没有 NPC 时显示「暂无角色记录」，不新增头像。刷新同聊天数据、切Tab或收起面板保留展开选择，换聊天清除。

## 房车物资 Tab

物资列表由紧凑平铺卡片组成。首行左侧显示「物品名 × 数量＋单位」，右侧显示统一配色的状态胶囊；中间直接显示完整说明，最下一行以定位图标和文字左对齐显示存放位置，上方有细分隔线。不按状态文字分配颜色。不显示「状态」「说明」「存放」标签，除位置行的图标与分隔线外不增加字段标签或展开按钮，卡片不可点击展开。

例如咖啡豆卡片：首行左侧「咖啡豆 ×4 袋」、右侧「3袋未开封，1袋已开封」，下方直接显示「每袋500克，其中1袋已开封取用」，下方位置行为定位图标和「厨房柜子」。物品数量 0 正常显示，不自动删除卡片。

窗口宽于800px时三列，不宽于800px时两列，不宽于520px时单列；同一行卡片自动等高。长名称、状态与说明自然换行并撑高所在行，不互相覆盖、不截断内容。没有记录时显示「暂无房车物资记录」。

## 随身物品 Tab

顶部按持有人胶囊切换，默认查看主角；姓名使用数据中的持有人原值。同聊天刷新、切Tab和收起大框保留选择，换聊天恢复默认。平铺、对齐、等高、状态配色与宽窄布局沿用房车物资。首行左侧为物品名和数量单位，右侧为状态，下方直接显示完整说明；卡片中不重复顶部已选的持有人。

例如主角的手机：左上为「iphone 17 pro max ×1 部」，右上为「正常满电」，下方为「日常生活使用」。不增加物资表才有的存放位置字段。

选中持有人没有记录时显示「暂无随身物品记录」。

## 地图查询

地图配置在首次展开总览时读取，小悬浮框不读取配置或启动地图。收起后再展开沿用已读配置。

主角查询文本按「国家＋省份＋城市＋区域＋主角当前位置」组成；房车查询文本按「国家＋省份＋城市＋区域＋房车所在地点」组成。取地图服务返回的第一个有坐标的匹配项标点；无结果时不显示对应图标，已有的位置文字仍正常显示。未知层级不作为「未知」字样发给地图服务。

不反复核对地址，不要求玩家选择候选，不显示匹配详情或精度提示，不增加根据主角移动纠正房车查询文本的规则。地图查询仅用于显示，不回写剧情数据，不读取玩家设备定位。

后续变量更新规则可要求 AI 尽量使用真实地点名称描述地理范围和位置；不要求 AI 输出经纬度，也不为地图编造精确门牌。现有世界书规则尚未加入此要求。

采用高德 JS API 2.0 与地理编码。没有配置时在地图位置显示「地图 Key」和「安全密钥」输入框，以及「如何获取？」入口；入口打开说明模态框，含普通用户能照做的步骤及官方链接。关闭说明后填写两项，点击「保存并显示地图」。配置写入当前角色 char 库的 env 表，分别为 amap_key 和 amap_sec 两条记录，不进入剧情数据或模型输入。同角色其它聊天共享配置；再次打开读取已有配置，提供更改入口。具体结构、事务及文案见[配置与说明方案](状态栏代码设计与测试方案.md#高德配置表与保存)。免费额度、可用区域和海外权限以实际账户为准，不承诺免费全球覆盖。

保存成功提示显示5秒后自动消失，错误提示保留供用户处理。地图独立页面通过CSS隐藏高德Logo图片（图片同时含「高德地图」文字），保留版权文字与审图号节点；样式不作用于酒馆其它地图。

## 明暗主题与旅行手册风格

主题提供「跟随系统」「浅色」「深色」三种选择。首次使用跟随浏览器的明暗偏好；手动选择后记住显示偏好，可以重新选择跟随系统。此偏好属于界面设置，不作为剧情变量。

浅色按世界信息的 `日期时间` 选择清晨、白天、傍晚或夜晚配色。深色使用暖炭灰背景和黄铜强调，不随时段换色；房车配图固定用夜晚图，场景卡仍可显示实际时段。地图始终使用官方 fresh 样式，不加暗色滤镜。所有具体色值维护在[主色值表](状态栏主色值表.md)。

| 时段 | 时间范围 | 浅色视觉 |
| --- | --- | --- |
| 清晨 | 06:00–08:59 | 淡紫背景、柔紫强调 |
| 白天 | 09:00–16:59 | 米白背景、暖金强调 |
| 傍晚 | 17:00–19:59 | 浅暖背景、橙棕强调 |
| 夜晚 | 20:00–次日 05:59 | 灰蓝背景、蓝紫强调 |

时间只读剧情数据，不读取电脑时钟。格式不是 `YYYY-MM-DD HH:mm`、值为「未知」、小时大于 23 或分钟大于 59 时，浅色用白天配色与白天图，但不显示时段标签。

正文与数值使用本机中文无衬线字体和等宽数字，标题使用本机衬线字体，不请求在线字体。面板图标统一为 Phosphor fill；地图标记和图例共用固定深绿 SVG。总标题只有一份「旅行手册」，左侧山峦徽记按时段或深色主题配色，等高线只作背景装饰，不接收点击或拖动。标题、主题选择和收起按钮可换行。

展开面板右上角在主题与收起之间提供「重新更新变量」，直接调用 `DVS.regen()` 重新处理当前最新 AI 回复，不生成新正文。DVS 尚未就绪时禁用；点击后改为「正在更新变量…」并禁用，收起重开仍保持等待，结束后恢复。结果沿用原更新通知重读；失败在内容区显示原因，换聊天清除旧错误。按钮沿用现有主题和标题换行布局。

展开面板标题栏在「重新更新变量」与「收起」之间提供「设置」按钮（齿轮图标加文字），小悬浮框不放。点击后打开与「如何获取」同样式的居中弹窗，打开时用 `DVS.getInject()` 读取当前脚本变量，读取失败时显示原因且不出现开关。弹窗提供两个开关，点击后立即调用 `DVS.setInject()` 并以读回值显示，失败时保持原状并显示错误：「输入增强」（发送前整理你的输入，优化提示词）、「剧情规划」（回复前先规划剧情走向，稳定正文生成）。剧情规划只在输入增强开启时可操作，输入增强关闭时剧情规划一并写为关闭并置灰，重新开启输入增强不自动恢复剧情规划。弹窗说明开启输入增强后每次发送消息会在生成正文前额外请求一次输入增强模型，剧情规划包含在同一次请求里，不再多一次；模型和参数在 sqlite-helper 插件的 DVS 设置中配置。

主背景、卡片和详情区以背景与细边区分层次，资源条、状态标签和选中提示使用各主题统一颜色。具体变量统一见[主色值表](状态栏主色值表.md)，实际浏览器核对可读性。

## 房车状态配图

房车配图统一使用设定中的 Unicat 6×6 重型越野房车：三根车轴、大尺寸越野轮胎、独立卡车驾驶室和后方箱式居住舱，不画成普通厢式或巴士房车。地图车辆图标也沿用这一轮廓。

房车信息的 `状态` 是车况自由文本；`行车状态` 只允许「行车／驻车」，`拓展状态`只允许「收起／展开」。外出、停车休息都属于驻车，任一拓展机构或升顶打开即为展开。字段由世界书规则和数据库 CHECK 约束，界面只读取，不订正数据。

| 字段条件 | 配图类型 | 标题旁标签 |
| --- | --- | --- |
| 行车状态为「行车」 | 行车 | 行车 |
| 不是行车，拓展状态为「展开」 | 展开 | 拓展展开 |
| 其余 | 驻车 | 驻车 |

行车优先，即使两个字段矛盾也显示行车图，不另做提示。每种类型各有四时段图，共 12 张；浅色按剧情时段选图，深色固定夜晚。同聊天数据或主题变化只更换图片，不重新挂载 Vue，不重置 Tab、角色展开或持有人，也不因此重查地图。

配图母版为 1586×992 PNG。行车、驻车窗口宽高比为 1586∶562，展开为 1586∶617；图片宽度为窗口的 100%，贴底显示，裁去顶部透明天空。编码、分辨率取舍与素材来源见[资源说明](状态栏素材.md)。配图是装饰，不表示真实地图位置或测量尺寸。

## 小悬浮框与大面板

小框纵向排列月日时分（例如 `06.18 16:40`）、城市、区域，再逐行排列水、电、油的实心图标与短进度条。资源不显示数值、单位或文字标签；读屏名称保留资源名称和值。时间来自剧情中的日期时间，不使用电脑时钟。小框初始参考尺寸为 130 × 160 CSS px，文字变化时自然排版，不强制裁掉长地名。

整个小框都可以点击展开、按住拖动，不设置额外按钮、箭头、拖动点或专属拖动区域。拖动超过 5 CSS px 后不触发展开；键盘 Enter／空格可以展开。触摸拖动仅在小框和大框可拖动标题部分禁用浏览器默认手势。

大面板沿用上文四个 Tab 和现有效果图的内容布局。标题栏显示「旅行手册」、主题选择及「收起」按钮，空白和标题文字区域可拖动，按钮与选择控件不发起拖动。大框建议宽 900 CSS px、高度最多 720 CSS px；实际宽高受当前可见窗口限制。标题栏不随内容滚动，内容在自己的滚动区内滚动。收起保留当前 Tab、展开卡片和持有人，地图可停止显示；应用本身不销毁。

小框初次放在窗口右侧偏上方，保留 8 CSS px 边距。小、大框分别保留本次页面中的拖动位置，展开先参考小框附近位置，再按实际大小限制位置。位置不持久化，不增加剧情变量；重新加载回到默认位置。主题偏好按本文主题规则保存。

## 窗口变化与可操作范围

拖到任一边界、展开／收起、窗口大小变化、浏览器缩放、可见窗口移动、内容尺寸变化时，都重新测量并修正位置。判断使用酒馆主窗口的可见区域和实际 DOM 尺寸，不使用脚本 iframe 的尺寸。

小框的完整矩形保持在可见窗口内。大框先按窗口宽高限制外框，确保整个标题栏、主题选择和收起按钮可见；正文区域允许内部滚动。空间不足时缩小边距和卡片列数，不能以固定最小宽度把收起按钮推出屏幕。长标题可以换行，收起按钮不允许被挤掉。窗口高度极小时保留标题操作区，内容可为零高度；只有可见区域本身容不下一个操作控件时才无法保证完整面板，此限制要如实报告。

尺寸与位置修正、点击与拖动区分、宽窄排版和验证标准见[代码设计与测试方案](状态栏代码设计与测试方案.md)。实测还需核对酒馆设置面板、遮挡、层级和点击结果，不能只证明坐标在屏幕内。

## 渲染与数据读取

采用 Vue 3，一个应用管理收起／展开、Tab、主题、卡片展开、持有人以及读取所得数据；不使用路由、Pinia 或组件库。模板本地预编译，再使用酒馆助手脚本环境的 Vue runtime。面板使用 Phosphor 图标，地图与等高线使用 SVG，房车配图使用构建时缩小的透明 WebP，配色按[主色值表](状态栏主色值表.md)。脚本源代码、构建输出和房车卡配置的接入见[代码方案](状态栏代码设计与测试方案.md)。

房车 DVS 作者脚本继续承担唯一注册，独立界面脚本只读取。界面通过 `DVS.onRegistrationChange()` 接收当前注册状态及后续变化，解决两个脚本不同启动顺序；不调用第二次 `DVS.register()`。注册状态订阅跨重新注册持续，数据与进度订阅绑定各次注册，作者脚本重新注册时重新绑定后两者。首次读取及 `DVS.onUpdate` 后重新取得 `DVS.getState()`，读取六张表的显示副本，不保留可以写入的行对象。

同一聊天数据暂不可读时保留上次读取成功的数据，并提示「当前状态暂不可读，显示上次已读取数据」。第一次读取失败则显示「暂无可读状态」，详细错误可以查看。切换聊天立刻清空旧数据、卡片展开、持有人及地图标记，再读取新聊天；失败也不能显示旧聊天内容。旧异步查询完成时若聊天、回复或 swipe 已改变，丢弃该结果。通知仅表示需要重读，不是整轮成功或文件保存确认。

删除楼层、切回已有 swipe、同角色切换聊天和变量更新结束等通知按[现行 DVS 契约](https://github.com/q3boy/st-sqlite-helper/blob/master/doc/dvs/指南/DVS作者使用手册.md)处理。正常正文、重新生成和新 swipe 成功完成后，由 DVS 自动更新变量；悬浮栏只在通知后重读。原生消息变化用来使旧查询失效和说明数据尚不可读，不由界面额外调用模型或 `regen()`。界面通过 `DVS.onUpdateStatus()` 读取变量更新进度，注册有效后绑定，关闭或重新注册时释放旧订阅。`onUpdate` 表示数据需要重读，进度通知也不代表文件已保存。

脚本关闭／换角色时取消自己的订阅和监听、销毁地图、执行 Vue unmount、移除主页面挂载节点和样式。一个脚本只拥有自己的节点。补货或数据编辑另行设计，不进入本轮。

## 实现边界

状态栏由房车卡独立实现，只新增当前角色 char 库的地图配置 env 表，不修改 DVS 公共协议、聊天业务表、正文状态栏标签或楼层正则，不提供历史楼层面板。DVS 公共能力见[作者使用手册](https://github.com/q3boy/st-sqlite-helper/blob/master/doc/dvs/指南/DVS作者使用手册.md)。详细方案和自动化验收入口见[代码设计与测试方案](状态栏代码设计与测试方案.md)；程序与模拟浏览器结果不代替真实酒馆或真实高德验证。
