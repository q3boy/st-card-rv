# 房车状态栏素材

状态栏使用 `状态栏素材/` 中的 12 张房车 PNG 母版和 3 份 SVG。PNG 在构建时等比缩小并编码为透明 WebP；面板图标使用 Phosphor Vue 组件。配图只用于界面装饰，不是测量图或真实地图。主题变量见[主色值表](状态栏主色值表.md)。

## 房车配图

母版位于 `房车配图/`，均为 1586×992、带 Alpha 通道的 PNG。行车、驻车和拓展展开各有清晨、白天、傍晚、夜晚四张，共 12 张：

| 时段 | 行车 | 驻车 | 拓展展开 |
| --- | --- | --- | --- |
| 清晨 | [rv-drive-dawn.png](../状态栏素材/房车配图/rv-drive-dawn.png) | [rv-park-dawn.png](../状态栏素材/房车配图/rv-park-dawn.png) | [rv-expand-dawn.png](../状态栏素材/房车配图/rv-expand-dawn.png) |
| 白天 | [rv-drive-day.png](../状态栏素材/房车配图/rv-drive-day.png) | [rv-park-day.png](../状态栏素材/房车配图/rv-park-day.png) | [rv-expand-day.png](../状态栏素材/房车配图/rv-expand-day.png) |
| 傍晚 | [rv-drive-dusk.png](../状态栏素材/房车配图/rv-drive-dusk.png) | [rv-park-dusk.png](../状态栏素材/房车配图/rv-park-dusk.png) | [rv-expand-dusk.png](../状态栏素材/房车配图/rv-expand-dusk.png) |
| 夜晚 | [rv-drive-night.png](../状态栏素材/房车配图/rv-drive-night.png) | [rv-park-night.png](../状态栏素材/房车配图/rv-park-night.png) | [rv-expand-night.png](../状态栏素材/房车配图/rv-expand-night.png) |

[art.ts](../状态栏/art.ts) 显式导入全部配图。[display.ts](../状态栏/display.ts) 根据 `行车状态`、`拓展状态` 选择配图类型：行车时用 `drive`；非行车且拓展展开时用 `expand`；其余用 `park`。[总览组件](../状态栏/OverviewTab.vue) 在浅色下按世界信息的日期时间选择时段，时间不可识别时使用白天图；深色下统一使用对应类型的夜晚图。

PNG 母版保留完整画幅和透明天空，构建不修改原文件。界面按插画区 100% 宽度等比显示，底部对齐，裁去顶部透明天空；行车和驻车窗口比例为 1586:562，展开窗口为 1586:617，车辆保持完整。

## SVG 与面板图标

当前 SVG 集中在 `图形/`，来源和用途见[素材与许可清单](../状态栏素材/vector-assets.json)：

| 文件 | 用途 |
| --- | --- |
| [map-person.svg](../状态栏素材/图形/map-person.svg) | 地图主角标记及图例 |
| [map-rv.svg](../状态栏素材/图形/map-rv.svg) | 地图房车标记及图例 |
| [title-contours.svg](../状态栏素材/图形/title-contours.svg) | 标题栏等高线装饰 |

地图标记与图例共用固定深绿 `#214D47` 的两份 SVG，浅深主题保持一致；标记由地图 iframe 插入，图例通过 `img` 显示。标题等高线作为 CSS 遮罩，以主题强调色显示。三份 SVG 均为本项目绘制，保留原始几何和 viewBox。

面板图标由 [icons.ts](../状态栏/icons.ts) 映射到 `@phosphor-icons/vue`，在 [Icon.vue](../状态栏/Icon.vue) 中统一使用 `fill` 字重。标题山峦徽记由 [Emblem.vue](../状态栏/Emblem.vue) 绘制，并按时段和深色模式配色。

插画、地图图例和装饰不承载业务交互；图片使用空 alt、`aria-hidden` 和 `draggable=false`，组件 SVG 也不提供重复的读屏内容。

## 编码、许可与构建

[构建脚本](../scripts/build.ts) 只处理源码显式导入的素材：

- PNG 按 888 像素宽等比缩小，使用 Lanczos3，不放大原图；WebP 参数为 `lossless: false`、`quality: 90`、`alphaQuality: 100`、`effort: 6`。编码保留完整画幅，界面裁切不写回素材。
- WebP 输出到 `images/房车配图/rv-<类型>-<时段>.webp`，SVG 原样输出到 `images/图形/<文件名>.svg`。两类资源同时编码为 data URL，随单个 IIFE 携带，不请求本机素材地址。
- `build.json` 记录源文件和输出文件的路径、SHA-256、字节数及尺寸；WebP 记录 Alpha，SVG 记录 viewBox。
- `vector-assets.json` 维护三份 SVG 的来源以及 Phosphor 的 MIT 许可文本；构建将第三方许可写入 IIFE 注释和 `THIRD-PARTY-LICENSES.txt`。

更多构建入口见[代码与构建说明](状态栏代码设计与测试方案.md#文件与构建)。[确认稿]
