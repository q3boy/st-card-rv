# 房车卡测试

从房车仓库根目录执行命令，入口与环境见[开发说明](../doc/README.md#独立开发环境)，具体行为要求见[状态栏代码设计与测试方案](../doc/状态栏代码设计与测试方案.md#自动化测试)。

- `core` 用 Bun 检查房车业务与状态栏，`tools` 用 Bun 检查仓库工具，`browser` 用 Playwright Chromium，`support` 仅放多个用例共用的准备与观察代码。用例按具体触发条件和结果命名；移动或拆合后核对运行器仍执行原场景，包括参数化、条件跳过和准备／清理钩子。
- 修改作者回调时执行真实 `脚本/DVS.js`；SQL 检查使用本库真实 sql.js。模拟对象只提供状态栏消费的公开形状，不将其结果写成 DVS ORM、INIT、Worker 或文件保存证据。`narrative-filter` 核对作者内容与调用参数，不证明 DVS 内部请求构造和模型筛选协议。
- 异步、切换与取消测试先确认调用到达被测步骤，再释放受控 Promise 或触发切换。测试失败先检查准备数据和同步点，再判断产品问题；不以等待时间证明前提成立。
- 保留用例时同时保留其触发条件、产品路径和结果断言。删减组合验证必须说明实际失去的证据；多个独立模拟测试不能声称等价替代原协作检查。
- 浏览器执行最终 IIFE，使用真实 Vue、DOM、事件与布局；Helper、DVS 和高德仍为模拟。截图前等数据、图片 decode、字体与布局稳定，记录构建编号；界面变化核对宽窄、展开收起及遮挡。实际酒馆验证按[部署流程](../doc/真实酒馆部署验证流程.md)另行授权。
- 自动产物放本库 `.test-data/card-rv`，使用隔离构建。交付前按影响运行类型检查及相关核心／浏览器测试，报告模拟和真实环境边界。清理按[限定范围](../doc/README.md#清理与工具)执行，保留仍需恢复的备份。
